CRAFT EDUCATIVO V4

Novedades:
- Editor 2D de planta mediante cuadrícula editable.
- 0 = espacio libre; 1 = D1; 2 = D2; etc.
- Verificación automática de áreas y conectividad.
- Cálculo automático de centroides.
- Distancia rectilínea o euclidiana.
- Costo Z = suma(fij*cij*dij).
- Experimentación manual antes de optimizar.
- CRAFT por intercambio de pares y auditoría.
- Comparación gráfica antes/después.
- Exportación a Excel.

Caso de prueba incluido:
Planta 20 x 10 m; áreas 60, 40, 80, 20 m²; matriz From-To del ejercicio.
Con distancia euclidiana, el layout inicial por franjas reproduce Z = 344.50.

IMPORTANTE:
Para editar la geometría, cambie directamente los números de las celdas en la cuadrícula.
El programa impide optimizar mientras las áreas no coincidan o un departamento esté desconectado.
