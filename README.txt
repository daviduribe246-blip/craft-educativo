CRAFT EDUCATIVO - V1

1. Instale Python 3.11 o 3.12.
2. Abra CMD en esta carpeta.
3. Ejecute: pip install -r requirements.txt
4. Luego haga doble clic en INICIAR_CRAFT.bat

Incluye: departamentos configurables, áreas, From-To, costos, planta en celdas,
centroides, distancia rectilínea/euclidiana, costo F*C*D, mejora CRAFT,
conectividad, comparación antes/después y exportación a Excel.

Nota metodológica: los intercambios completos se realizan para departamentos de
igual área. Para áreas desiguales, la V1 incorpora un vecindario ampliado de
intercambios de celdas fronterizas que preserva área y conectividad. Esta
extensión debe distinguirse del intercambio clásico de departamentos completos.
